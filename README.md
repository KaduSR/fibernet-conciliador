# FiberNet Conciliador 💰

> Conciliação financeira automatizada para provedores de internet · Automated financial reconciliation for Internet Service Providers

---

## 🇧🇷 Português

Sistema de conciliação financeira entre **IXC Soft** e **Sicoob**, desenvolvido para **Telecom Fiber Net Ltda**. Automatiza a comparação de boletos, pagamentos e transações entre sistemas de telecom e instituições financeiras.

### ✨ Funcionalidades
- Conciliação automática de boletos e pagamentos
- Integração com IXC Soft (sistema de telecom)
- Integração com Sicoob (banco)
- Geração de relatórios de diferenças
- Dashboard de conciliação em tempo real

### 🛠 Stack
- **Linguagem:** TypeScript
- **Framework:** Node.js
- **Banco:** PostgreSQL
- **Deploy:** Docker, Vercel

### 📊 Fluxo
```
IXC Soft (boletos) ──┐
                      ├─── FiberNet Conciliador ──→ Diferenças / Relatórios
Sicoob (pagamentos) ─┘
```

### 🚀 Como usar
```bash
git clone https://github.com/KaduSR/fibernet-conciliador.git
cd fibernet-conciliador
npm install
npm start
```

---

## 🇺🇸 English

Financial reconciliation system between **IXC Soft** and **Sicoob**, developed for **Telecom Fiber Net Ltda**. Automates the comparison of invoices, payments, and transactions between telecom systems and financial institutions.

### ✨ Features
- Automated invoice and payment reconciliation
- Integration with IXC Soft (telecom system)
- Integration with Sicoob (bank)
- Discrepancy report generation
- Real-time reconciliation dashboard

### 🛠 Stack
- **Language:** TypeScript
- **Framework:** Node.js
- **Database:** PostgreSQL
- **Deploy:** Docker, Vercel

### 📊 Flow
```
IXC Soft (invoices) ──┐
                       ├─── FiberNet Conciliador ──→ Discrepancies / Reports
Sicoob (payments) ────┘
```

### 🚀 Usage
```bash
git clone https://github.com/KaduSR/fibernet-conciliador.git
cd fibernet-conciliador
npm install
npm start
```
